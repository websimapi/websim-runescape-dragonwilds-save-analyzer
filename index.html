About RuneScape Dragonwilds Save Files

RuneScape Dragonwilds save files (.sav) contain all the information about your game world including:

  • World settings (name, map type, friendly fire settings)
  • Player information and progress
  • Object placements and properties
  • Game state and metadata

File Structure

The save file has a binary format with the following general structure:

  1. Header - Contains the "SAVE" signature and version information
  2. Metadata - Includes timestamp and world basic information
  3. World Settings - Contains world name, map type, and game rules
  4. Player Data - Contains player inventories, stats, and positions
  5. Game Objects - Information about all objects in the world

JSON Data in Save Files

RuneScape Dragonwilds save files contain embedded JSON data structures that hold important game information. Common JSON structures include:

Inventory Data

Contains information about the player's items, including counts, item types, and unique identifiers. These structures typically have "GUID" fields and "Count" properties.

{
  "Version": 53,
  "0": {
    "GUID": "HXsFKUOVu6OiwdKZw-9Amg",
    "ItemData": "qOY004ZJaEaR8DmcDqB2KA",
    "Count": 6
  },
  /* more items */
}

Event Definitions

Contains information about game events, triggers, and actions.

{
  "Version": 2,
  "Definitions": [
    {
      "Id": "EventId",
      "Type": "TriggerType",
      "Enabled": true
    }
  ]
}

Game Statistics

Contains various game metrics and player statistics.

{
  "Version": 1,
  "PlayTime": 3600,
  "Deaths": 5,
  "ItemsCrafted": 42
}

JSON Type Categories

The AI will identify various JSON structure types, including:

  • Inventory - Player's items, counts, and equipment
  • PlayerStats - Character attributes, levels, and status
  • QuestLog - Mission progress and quest states
  • WorldState - Environment conditions and world status
  • GameSettings - Configuration options and preferences
  • EventData - Game events, triggers, and actions
  • And more... - The AI learns from the specific structures in your save file

Understanding JSON Data Types

When editing JSON data, it's essential to understand the different data types:

  • Strings - Text enclosed in quotes, like "HXsFKUOVu6OiwdKZw-9Amg"
  • Numbers - Numeric values without quotes, like 6 or 53
  • Booleans - Either true or false without quotes
  • Objects - Collections of key/value pairs enclosed in {} braces
  • Arrays - Ordered lists of values enclosed in [] brackets

Always keep the same data type when editing values. For example, don't change 6 to "6" or true to "true".

Editing JSON Data

When editing JSON data in save files, follow these guidelines:

  • Maintain Structure - Don't change the overall structure of the JSON
  • Preserve Types - Keep the same data types (strings, numbers, booleans) as in the original
  • IDs and GUIDs - Be careful when modifying IDs or GUIDs as these are used to reference objects
  • Backup First - Always create a backup before making changes

Editing Tips

  • Use the "Format JSON" button to make the JSON more readable
  • You can modify item counts, resources, and some settings safely
  • Avoid editing complex nested structures unless you know exactly what they do
  • Size changes are risky - try to keep the overall size of the JSON similar
